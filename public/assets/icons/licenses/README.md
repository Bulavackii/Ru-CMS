# Лицензии наборов значков

Здесь лежат условия использования всех наборов, которые раздаёт сайт. Файлы
раздаются вместе с CMS, поэтому и условия должны лежать рядом с ними — это
требование почти всех перечисленных лицензий.

Проверено 09.08.2026. Обновлять вместе с наборами: `python scripts/vendor-icons.py`.

| Набор | Лицензия | Что требует | Значков |
|---|---|---|---|
| Lucide | ISC | сохранить текст лицензии | ~1500 |
| Phosphor Icons | MIT | сохранить текст лицензии | 1530 |
| Boxicons | MIT | сохранить текст лицензии | 1634 |
| Bootstrap Icons | MIT | сохранить текст лицензии | ~2050 |
| Tabler Icons | MIT | сохранить текст лицензии | ~5900 |
| Remix Icon | Remix Icon License v1.0 (на условиях Apache 2.0) | сохранить текст лицензии | ~2670 |
| Font Awesome Free | CC BY 4.0 (значки), SIL OFL 1.1 (шрифты), MIT (код) | **указание авторства** | ~2000 |

## На что обратить внимание

**Font Awesome Free — единственный набор, требующий указания авторства.**
Остальные достаточно сопроводить текстом лицензии, что и сделано этой папкой.
CC BY 4.0 разрешает коммерческое использование, в том числе в закрытом
продукте, но требует назвать автора. Если этого делать не хочется, набор в
теме можно не выбирать: любой из остальных шести закрывает те же потребности,
а по умолчанию стоит Lucide.

**Ни один набор не запрещает продажу продукта** и не требует открывать
исходный код — по этому признаку они и отбирались. Наборы под платной
подпиской (Font Awesome Pro, Streamline и подобные) сюда не берутся.

## Откуда что взялось

Адреса, версии и порядок скачивания записаны в `scripts/vendor-icons.py`.
Скрипт же переписывает пути к файлам шрифтов на свои: в рантайме сайт не
обращается наружу ни за одним значком.
