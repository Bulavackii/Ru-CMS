## 🎨 Общие классы

Объявлены в `layouts/admin.blade.php` литеральным CSS — потому что нужных
утилит Tailwind в сборке нет.

| Класс | Что делает |
|:---|:---|
| `.admin-glass` | Полупрозрачная полоса (на сенсорных — сплошная) |
| `.admin-card` | Карточка |
| `.admin-icon-badge` | Градиентный значок раздела |
| `.admin-hint` | Подсказка |
| `.admin-toggle` | Рабочий тумблер (вариант `peer-checked:` в сборке отсутствует) |
| `.admin-accent-bar` | Акцентная полоса над шапкой раздела |
| `.admin-sharp` | На `<body>`: прямые края во всей панели |

### Шапка раздела — `mh`

Два ряда на сенсорных, **одна строка на десктопе**:

```blade
<div class="admin-glass mh …">
    <div class="mh-row">
        <span class="admin-icon-badge">…</span>
        <h1 class="mh-title truncate">Название</h1>
        <span class="mh-status st-chip st-on">Опубликовано</span>
    </div>
    <div class="mh-row mh-row--sub">
        <div class="mh-facts">ID · адрес</div>
        <div class="mh-back">ссылки</div>
    </div>
</div>
```

> ⚠️ **Осторожно**
> **Определение лежит ВНЕ медиазапроса.** Внутри сенсорного блока оно оставляло
> десктоп сломанным: оба ряда получали полную ширину и налезали друг на друга.

### Списки

| Класс | Прячется | Чем помечать |
|:---|:---|:---|
| `col-extra` | ≤1024 | Второстепенные колонки: автор, дата, просмотры |
| `col-narrow` | ≤520 | То, без чего можно на телефоне |
| `col-grow` | — | Главная колонка: забирает свободное место |
| `st-chip` + `st-on`/`st-off` | — | Состояние: ниже 520 остаётся один значок |
| `tbl-2rows` | ≤720 | Строка становится сеткой, кнопки уходят нижним рядом |
| `only-keyboard` | ≤1024 | Подсказки о клавишах |
| `only-wide` | ≤1024 | Пояснения, которые на телефоне лишние |
| `only-narrow` | >520 скрыт | Строка, ЗАМЕНЯЮЩАЯ скрытые колонки |

> ⚠️ **Осторожно**
> **`tbl-2rows` можно ставить, только если кроме действий в строке не больше трёх
> видимых ячеек.** Колонок в сетке ровно три; четвёртая забирает `auto`-колонку,
> а растущей достаётся остаток — в списке SEO адрес ужался до буквы в строке.

> ⚠️ **Осторожно**
> **Колонку с названием помечать нельзя.** Массовая пометка однажды скрыла ячейку
> заголовка вместе со ссылкой на правку — открыть материал стало нечем.

## ✍️ Редактор содержимого (RU Editor)

Свой редактор, заменивший TinyMCE (причина — лицензия: TinyMCE 8 распространяется
под GPLv2+ либо по коммерческому договору, а CMS продаётся закрытой).

| Файл | Что внутри |
|:---|:---|
| `ru-editor.js` | Ядро: рамка, выделение, история, чистка разметки, реестры |
| `ru-editor-ui.js` | Диалоги, вкладки, подтверждения |
| `ru-editor-format.js` | Начертания, блоки, шрифт, цвет, списки, ссылки |
| `ru-editor-media.js` | Картинки, видео, медиатека, загрузка |
| `ru-editor-blocks.js` | Таблицы, блоки `pc-*`, спецсимволы, каптча |
| `ru-editor-tools.js` | Развернуть, исходник, предпросмотр, поиск, черновик |
| `components/ru-editor.blade.php` | Единственная точка подключения |

```blade
<x-ru-editor name="content" :value="$news->content" :height="520" />
```

### Что важно знать

> ❗ **Важно**
> **Рамка редактирования — IFRAME, и это не прихоть.** Оформление содержимого
> написано под страницу сайта, а вокруг лежат сброс Tailwind, `border-radius:0
> !important` и стили раздела. В общем документе они протекают внутрь текста, и
> автор видит не то, что увидит посетитель.

> ❗ **Важно**
> **История отмены своя.** Браузерная знает только про набор текста; операции над
> таблицами и блоками написаны на Range и в неё не попадают.

> ❗ **Важно**
> **Всё уходящее в базу чистится по белому списку.** Содержимое выводится через
> `{!! !!}`, поэтому любой `on*`-атрибут — чужой код на странице посетителя.

> ⚠️ **Осторожно**
> **Полноэкранного перекрытия НЕТ и возвращать его не нужно.** Оно давало рябь
> изображения у владельца; три попытки починить не помогли, а последняя ещё и
> стирала содержимое (перенос узла с `<iframe>` перезагружает фрейм).

### Расширение

```js
RuEditor.registerCommand('myThing', (editor, value) => { /* меняем документ */ });
RuEditor.registerButton('myThing', { icon: 'fas fa-star', command: 'myThing' });
RuEditor.registerPlugin('my-plugin', { init: (editor) => { /* подписки */ } });
```

Строки интерфейса — в словаре `admin.editor.js`, в скрипт русский текст не зашивают.

## 🌍 Локализация панели

- Словари: `resources/lang/{ru,en}/admin.php` — вложенные секции (`header`,
  `sections`, `common`, `news`…).
- `ru` — эталон, `en` — запасной (`fallback_locale`).
- Строки для Alpine и JS выводятся через `@js(__('...'))`, а не `{{ }}`.

> ⚠️ **Осторожно**
> **`@json(...)` внутри HTML-атрибута ломает атрибут** — выводит JSON в двойных
> кавычках, и первая же кавычка закрывает `onclick="`. Нужен `@js(...)`.

Сверка паритета ключей:

```bash
php -r '$r=array_keys((include "resources/lang/ru/admin.php")["files"]); $e=array_keys((include "resources/lang/en/admin.php")["files"]); var_dump(array_merge(array_diff($r,$e),array_diff($e,$r)));'
```

## 🎭 Темы панели

Панель берёт акцент из активной темы (`--admin-primary`), личный выбор
администратора хранится в `session('admin_theme')`. Цвет надписи поверх акцента
считается `readable_ink()` по WCAG — акценты тем очень разной яркости.

> 📌 **Заметка**
> **Тёмной темы в панели нет.** В статической сборке Tailwind отсутствуют все
> `dark:`-варианты; переключатель когда-то ставил класс `.dark`, применять его
> было нечему. Кнопка убрана, флаг в `localStorage` чистится.
