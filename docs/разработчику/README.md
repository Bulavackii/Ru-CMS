## ⚡ Пять минут на вход

```bash
git log --oneline -5                   # что было в прошлый раз
git status --short                     # незакоммиченное
php vendor/bin/phpunit --no-coverage   # базовая линия
php artisan route:list --path=admin    # карта панели
```

> ❗ **Важно**
> **Главный документ проекта — `CLAUDE.md` в корне.** Там журнал сессий с
> разбором первопричин: что ломалось, почему и чем чинили. Эти файлы — выжимка
> и систематизация; `CLAUDE.md` — источник.

## 🧭 Договорённости, которые не обсуждаются

| Правило | Почему |
|:---|:---|
| **Комментарии и коммиты по-русски** | Их читает владелец проекта |
| **База — PostgreSQL** | Осознанный выбор; тесты гоняются на SQLite ради скорости |
| **Миграции только в `database/migrations/`** | Внутри модуля миграция молча не выполнится |
| **Миграции драйвер-нейтральные** | Schema Builder, а не сырой SQL: прод Postgres, тесты SQLite |
| **Всё новое — в сидер** | Чистая установка обязана выглядеть как боевой сайт |
| **Правка вёрстки — с замером** | «Выглядит нормально» не считается результатом |
