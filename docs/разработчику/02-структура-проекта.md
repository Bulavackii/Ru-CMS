## 🗂️ Дерево верхнего уровня

```
cms/
├── app/                    ядро приложения
│   ├── Console/Commands/       команды уровня приложения
│   ├── Http/
│   │   ├── Controllers/        сайт, панель, вход, API
│   │   └── Middleware/         установка, права, безопасность, локаль
│   ├── Jobs/                   фоновые задачи
│   ├── Listeners/              слушатели событий
│   ├── Models/                 User, Role, Setting…
│   ├── Providers/              ModuleServiceProvider, ThemeServiceProvider…
│   ├── Support/                AdminSections, AdminCounters, QrCode
│   └── helpers.php             общие функции
│
├── modules/                22 модуля (см. ниже)
├── database/migrations/    ВСЕ миграции, включая модульные
├── resources/
│   ├── views/                  вьюхи ядра: лейауты, фронт, панель, письма
│   ├── lang/{ru,en}/           словари
│   ├── js/ css/                исходники Vite
│
├── public/
│   ├── assets/                 готовые css/js/шрифты/значки — без сборки
│   ├── images/                 картинки продукта
│   └── storage → symlink       на storage/app/public
│
├── routes/                 web.php, api.php, auth.php (мёртвый)
├── tests/                  Unit + Feature
├── docs/                   эта документация
└── CLAUDE.md               журнал сессий и разбор первопричин
```

## 📁 Анатомия папки модуля

```
modules/News/
├── Controllers/
│   ├── Admin/NewsController.php      панель
│   └── Frontend/NewsController.php   сайт
├── Models/News.php
├── Views/
│   ├── admin/                        экраны панели
│   └── frontend/                     вьюхи сайта
├── Routes/
│   ├── web.php                       маршруты сайта
│   └── admin.php                     маршруты панели
├── Console/Commands/                 свои artisan-команды
├── Services/                         логика, вынесенная из контроллеров
├── Providers/NewsServiceProvider.php регистрация модуля
└── module.json                       имя, версия, описание, приоритет
```

> 📌 **Заметка**
> Часть модулей хранит вьюхи в `Resources/views` вместо `Views` (Visual,
> Notifications, Forms). Оба варианта поддерживаются загрузчиком — при правке
> смотрите, как устроен конкретный модуль.

## 🎯 Где что искать

| Нужно | Путь |
|:---|:---|
| Лейаут панели | `resources/views/layouts/admin.blade.php` |
| Шапка, подвал, сайдбар панели | `resources/views/layouts/admin/*.blade.php` |
| Лейаут сайта | `resources/views/layouts/frontend.blade.php` |
| Шаблоны материалов | `resources/views/frontend/templates/*.blade.php` |
| Оформление блоков содержимого | `public/assets/css/content-blocks.css` |
| Редактор | `public/assets/js/ru-editor*.js` + `resources/views/components/ru-editor.blade.php` |
| Разделы панели (единый список) | `app/Support/AdminSections.php` |
| Счётчики «есть новое» | `app/Support/AdminCounters.php` |
| Словари | `resources/lang/{ru,en}/*.php` |
| Мастер установки | `modules/Install/Controllers/InstallController.php` |

## ⚠️ Особенности, о которых лучше знать заранее

> ⚠️ **Осторожно**
> **`public/assets/` — это готовые файлы, а не результат сборки.** Стили Tailwind,
> Alpine, значки и шрифты лежат там как есть. `npm run build` их не пересобирает.

> ⚠️ **Осторожно**
> **`routes/auth.php` не подключается.** Стоковый файл Breeze; у приложения свои
> контроллеры входа. Нужные оттуда маршруты перенесены в `web.php` поштучно.

> 📌 **Заметка**
> **`storage/install.lock`** — признак «система установлена». Файл машинно-локальный
> и в git не хранится. Его отсутствие уводит любой запрос на `/install`.
> В тестах используется отдельный путь — см. [Тесты](09-тесты-и-проверки.md).
