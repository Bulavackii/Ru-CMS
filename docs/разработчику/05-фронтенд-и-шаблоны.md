## 🎨 Шаблоны материалов

Шаблон — это вид материала на сайте. Один материал, разные шаблоны — разные
страницы.

**Реестр — `Modules\News\Controllers\Admin\NewsController::TEMPLATES`.**
Из него берутся и список в форме, и блоки главной страницы, и проверка при
сохранении.

| Ключ | Подпись | Файл |
|:---|:---|:---|
| `default` | Новости | `frontend/templates/default.blade.php` |
| `magazine` | Журнал | `magazine.blade.php` |
| `clinic` | Клиника | `clinic.blade.php` |
| `gaming` | Игры | `gaming.blade.php` |
| `products` | Товары | `products.blade.php` |
| `ourworks` | Наши услуги | `ourworks.blade.php` |
| `faq` | Вопросы | `faq.blade.php` |
| `reviews` | Отзывы | `reviews.blade.php` |
| `release` | Релизы | `release.blade.php` |
| `slideshow` | Слайдшоу | `slideshow.blade.php` |
| `base-html` `base-css` `base-js` `base-php` `base-git` | Уроки | общий партиал `partials/lesson.blade.php` |

### Какой шаблон какое поле носит

Рядом с реестром — три списка, **единый источник** для контроллера и для формы:

```php
PRICE_TEMPLATES  = ['products', 'ourworks'];
STOCK_TEMPLATES  = ['products'];
RATING_TEMPLATES = ['gaming', 'reviews'];
```

> ⚠️ **Осторожно**
> **Эти списки были размазаны по четырём местам и разошлись.** Цена сохранялась
> только у «Товаров»: владелец открывал услугу, ничего не менял, нажимал
> «Сохранить» — и карточка на сайте переключалась на «По запросу».

### Как добавить шаблон

| Шаг | Что сделать |
|:--:|:---|
| 1 | Добавить ключ и подпись в `TEMPLATES` |
| 2 | Создать `resources/views/frontend/templates/<ключ>.blade.php` |
| 3 | Добавить подпись раздела в `frontend.templates.*` — **в оба словаря** |
| 4 | Если нужны цена/остаток/оценка — вписать ключ в соответствующий список |
| 5 | Завести демо-материалы в мастере установки |

Закреплено тестом `tests/Feature/LessonTemplatesTest.php`: реестр, файл и подпись
обязаны совпадать.

## 📚 Уроки: общий партиал

Пять шаблонов уроков — это **один** партиал `partials/lesson.blade.php`; шаблоны
задают только подпись, значок и цвет:

```blade
@include('frontend.templates.partials.lesson', [
    'lang' => 'Git', 'icon' => 'fa-git-alt',
    'accent' => '#f05033', 'ink' => '#ffffff',
    'shortKey' => 'git', 'template' => 'base-git',
])
```

> 📌 **Заметка**
> Раньше это были четыре полные копии одной вёрстки — и они уже разошлись: блок
> подсветки кода остался только у HTML.

**Сквозная нумерация** уроков берётся из `template_numbers()` (`app/helpers.php`):
пятый заведённый урок остаётся пятым, где бы он ни оказался в списке.

## 🧱 Блоки содержимого

`public/assets/css/content-blocks.css` — **один файл на два места**: им
оформляется содержимое на сайте, и он же подключается внутрь редактора
(`content_css` + `body_class: 'page-content'`). Поэтому блок в редакторе
выглядит так же, как у посетителя.

Классы: `pc-lead`, `pc-grid`/`pc-card`, `pc-ico`, `pc-stats`, `pc-steps`,
`pc-check`, `pc-note`, `pc-split`, `pc-tech`, `pc-cta`, `pc-faq`, `pc-contacts`,
`pc-map`.

Вставляются кнопкой **«Блоки»** редактора — `public/assets/js/ru-editor-blocks.js`.

## 🔤 Шорткоды

`render_shortcodes()` в `app/helpers.php`. Распознаются: `captcha`, `form`,
`map`, `sitemap`.

| Функция | Где применяется |
|:---|:---|
| `render_shortcodes($html)` | Вывод содержимого материала и страницы |
| `strip_shortcodes($html)` | Там, где содержимое становится простым текстом |

> ⚠️ **Осторожно**
> **`strip_shortcodes()` обязателен для мета-описаний.** Без него
> `[captcha preset="…"]` уезжал в описание страницы и был виден в поисковой
> выдаче.

## 📱 Адаптивность

**Единый порог во всём проекте:**

```css
@media (max-width: 1024px), (max-height: 500px) { … }
```

1024 включительно — планшет в альбомной ровно такой и он сенсорный; вторая
половина условия ловит телефон в альбоме.

| Приём | Смысл |
|:---|:---|
| Кегль не ниже **12px** | Мельче браузер предлагает увеличить страницу целиком |
| Зоны нажатия **44 / 32 / 24** | Основное действие / плотный набор / нижняя граница WCAG |
| Любой `:hover`-показ дублируется | На сенсорном экране наведения нет |

> ⚠️ **Осторожно**
> **Правило в макете НЕ перебивает правило в партиале.** Стили шапки, подвала и
> вьюх модулей подключаются `<style>`-ом в теле документа, то есть ниже `<head>`
> макета, и при равной силе побеждают они. Лечение — префикс `body` у селектора.

> ⚠️ **Осторожно**
> **`flex-wrap` отключает сжатие.** Элементы переносятся раньше, чем сработает
> `flex-shrink`, — на это уже дважды закладывались зря.

Журнал замеров сайта — [адаптивность-фронтенда.md](../адаптивность-фронтенда.md).

## 🖼️ Общие возможности сайта

| Возможность | Где живёт |
|:---|:---|
| Просмотр картинки во весь экран | `public/assets/js/image-viewer.js` — общий на весь сайт |
| Постраничный вывод | `resources/views/vendor/pagination/tailwind.blade.php` — **один файл на все 28 списков** |
| Время чтения | `reading_time()` в `app/helpers.php` |
| Контрастный цвет надписи | `readable_ink()` — по WCAG |

> ⚠️ **Осторожно**
> **`str_word_count()` не работает с кириллицей** — считает только латинские
> фрагменты. У страницы из 125 слов возвращала 3. Правильный подсчёт —
> `preg_match_all('/[\p{L}\p{N}]+/u', …)`. То же касается `strlen()`, `substr()`,
> `ucfirst()`: любая строковая функция без `mb_`/`/u` на русском тексте —
> подозреваемая.
