# ✍️ Редактор содержимого

**Свой редактор, без чужих лицензий и баннеров.**
Одинаково работает в новостях, страницах, письмах и фрагментах.

## 🎛️ Панель инструментов

| Группа | Что внутри |
|:---|:---|
| **Начертание** | Полужирный, курсив, подчёркнутый, зачёркнутый, верхний/нижний индекс |
| **Блок** | Абзац, заголовки H1–H6, цитата, код |
| **Списки** | Маркированный, нумерованный, отступы |
| **Выравнивание** | Слева, по центру, справа, по ширине |
| **Цвет** | Цвет текста и цвет заливки |
| **Ссылка** | Вставить, изменить, снять |
| **Картинка** | Загрузить с компьютера, выбрать из медиатеки, вставить по адресу |
| **Видео** | YouTube, Rutube, VK — вставкой ссылки |
| **Таблица** | Вставка, строки, столбцы, объединение ячеек |
| **Блоки** | Готовые оформленные блоки — см. ниже |
| **Символы** | Тире, кавычки-ёлочки, знаки валют, стрелки |
| **Каптча** | Вставить проверку «я не робот» в материал |
| **Инструменты** | Развернуть на высоту окна, исходный код, предпросмотр, поиск и замена |

> 💡 **Совет**
> `Ctrl + S` сохраняет материал, не выходя из редактора.
> `Ctrl + Z` / `Ctrl + Y` — отмена и возврат, включая действия с таблицами.

## 🧱 Кнопка «Блоки» — верстка без вёрстки

Это главная кнопка редактора. Она вставляет готовый оформленный блок, который на
сайте выглядит как сделанный дизайнером.

| Блок | Для чего |
|:---|:---|
| 📝 **Вводный абзац** | Крупный текст в начале материала |
| 🔲 **Карточки** | Три-четыре плитки со значком и подписью |
| 🔢 **Цифры** | «12 лет опыта · 500 клиентов · 24 часа» |
| 📋 **Шаги** | Пронумерованный порядок действий |
| ✅ **Галочки** | Список с отметками вместо точек |
| 💡 **Примечание** | Выделенная плашка с подсказкой |
| ↔️ **Две колонки** | Текст рядом с картинкой |
| ⚙️ **Характеристики** | Таблица «параметр — значение» |
| 📣 **Призыв** | Блок с кнопкой |
| ❓ **Вопросы-ответы** | Раскрывающийся аккордеон |
| 📞 **Контакты** | Телефон, почта, адрес карточками |
| 🗺️ **Карта** | Врезка карты |

**Как это работает:** блок вставляется с примерным содержимым — его нужно
заменить своим. Оформление берётся из общего файла стилей, поэтому блоки
одинаково выглядят и в редакторе, и на сайте.

## 🖼️ Картинки

| Способ | Когда удобнее |
|:---|:---|
| **Загрузить** | Картинка ещё не на сайте — попадёт и в материал, и в [Медиатеку](разделы/медиатека.md) |
| **Из медиатеки** | Картинка уже загружалась — выбирается из сетки с поиском и фильтром по категории |
| **По адресу** | Картинка лежит на другом сайте (не рекомендуется: чужой сайт может её удалить) |

У каждой картинки задаются **alt-текст** (что на ней — читают поисковики и
экранные дикторы) и подпись.

> 📌 **Заметка**
> Клик по картинке на сайте открывает её во весь экран. Это работает во всех
> материалах, отдельно включать не нужно.

## 🔤 Шорткоды

Короткая пометка в тексте, вместо которой на сайте появляется блок.

| Шорткод | Что вставляет |
|:---|:---|
| `[captcha preset="имя"]` | Проверку «я не робот» — [Каптча](разделы/каптча.md) |
| `[form slug="имя"]` | Форму заявки — [Формы](разделы/формы.md) |
| `[map]` | Карту |
| `[sitemap]` | Карту сайта списком |

Вставлять руками не обязательно: у каптчи и форм есть кнопка «скопировать
шорткод» в своём разделе, а каптча вставляется прямо из панели редактора.

---

## 🧹 Что редактор делает сам

- **Чистит разметку.** Всё, что вставлено из Word или с чужого сайта,
  приводится к аккуратному виду: убираются чужие шрифты, размеры и скрипты.
- **Приводит теги к одному виду.** `<b>` становится `<strong>`, `<i>` — `<em>`.
- **Не даёт вставить опасный код.** Обработчики событий и скрипты вырезаются:
  иначе чужой скрипт исполнился бы у посетителя.
- **Считает время чтения.** На сайте под заголовком видно «~4 мин» — считается
  по реальному числу слов, в том числе русских.

## ⚠️ На что обратить внимание

> ⚠️ **Осторожно**
> **Кнопка «Исходный код» — для тех, кто знает HTML.** Всё, что там написано,
> проходит ту же чистку при сохранении, поэтому «хитрая» разметка может
> упроститься.

> ⚠️ **Осторожно**
> **Развернуть на высоту окна ≠ полный экран.** Кнопка растягивает рамку прямо
> на странице. Полноэкранного режима нет намеренно: он давал рябь изображения на
> части видеокарт.

> 💡 **Совет**
> **Черновик.** Редактор сам сохраняет набранное в браузере. Если вкладка
> закрылась случайно — при следующем открытии материала он предложит вернуть
> несохранённое.
