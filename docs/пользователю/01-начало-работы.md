## 🔑 Вход

Панель живёт по адресу `/admin`. Если вы не вошли, система сама предложит форму входа.

| | |
|:---|:---|
| **Адрес панели** | `ваш-сайт.ру/admin` |
| **Логин** | почта, указанная при установке |
| **Забыли пароль** | ссылка «Восстановить» на форме входа — письмо придёт на почту |

> 📌 **Заметка**
> Восстановление пароля работает, только если на шаге установки была настроена
> почта. Если её пропустили — пароль меняется через раздел
> [Пользователи](разделы/пользователи.md) с другой учётной записи администратора.

### Вход в два шага

Если включена двухфакторная проверка, после пароля спросят шестизначный код из
приложения-аутентификатора (подойдёт **Яндекс Ключ**, Google Authenticator и любое
другое — используется общепринятый стандарт).

Телефон недоступен — на том же экране есть переключатель «ввести код
восстановления». Коды выдаются один раз при подключении проверки, каждый
работает однократно. Подробности — в [Пользователях](разделы/пользователи.md).

## 🧭 Устройство панели

```
┌──────────────────────────────────────────────────────────┐
│  ☰   На сайт        🔍 поиск           🔔  🎨  👤 Админ  │  ← шапка
├───────────┬──────────────────────────────────────────────┤
│ КОНТЕНТ   │                                              │
│  Меню     │                                              │
│  Новости  │              рабочая область                 │
│  Страницы │                                              │
│  …        │                                              │
│ СИСТЕМА   │                                              │
│  Модули   │                                              │
│  …        │                                              │
│ ПРОДАЖИ   │                                              │
│  Оплата   │                                              │
└───────────┴──────────────────────────────────────────────┘
│  Nexum Core 2.4.1 · PHP · Laravel · база · кеш · очередь     │  ← подвал
└──────────────────────────────────────────────────────────┘
```

| Элемент | Что делает |
|:---|:---|
| ☰ | На телефоне и планшете открывает меню разделов |
| **На сайт** | Открывает сайт в новой вкладке |
| 🔍 **Поиск** | Ищет разделы, материалы, страницы. Горячая клавиша — `Ctrl + K` |
| 🔔 | Уведомления системы: новые заказы, сообщения, отзывы |
| 🎨 | Оформление панели — выбор темы для себя, других не затрагивает |
| 👤 | Профиль, настройки учётной записи, выход |

### На телефоне

Панель полностью работает с телефона и планшета в любой ориентации. Отличия:

- разделы прячутся под ☰ — там же язык, оформление и служебные кнопки;
- в списках скрыты второстепенные колонки (автор, дата, просмотры);
- состояние показывается **значком**: 🟢 опубликовано, ⚪ черновик;
- подсказки про сочетания клавиш скрыты — клавиатуры там нет.

## 🏠 Главная панели

Открывается по `/admin`. Показывает:

| Блок | Смысл |
|:---|:---|
| **Приветствие и часы** | Кто вошёл и сколько времени |
| **Быстрые действия** | Создать материал, страницу, посмотреть сайт |
| **Числа** | Материалы, пользователи, заказы, сообщения |
| **График** | Прирост за последние дни |
| **Безопасность** | Что стоит починить: отладка включена, двухфакторная проверка не у всех |
| **Последние действия** | Кто и что менял |

## ⚠️ Три вещи, которые стоит знать сразу

> ⚠️ **Осторожно**
> **1. Публикация — отдельный переключатель.** Сохранённый материал не появится
> на сайте, пока не отмечен «Опубликовано».

> ⚠️ **Осторожно**
> **2. Часть блоков главной страницы обновляется до 5 минут.** Это сделано ради
> скорости сайта. Сама страница материала меняется сразу.

> ⚠️ **Осторожно**
> **3. Адрес материала (slug) лучше не менять после публикации.** По старому
> адресу могут быть ссылки и он уже попал в поисковики. Если менять
> необходимо — заведите перенаправление в разделе [SEO](разделы/seo.md).
