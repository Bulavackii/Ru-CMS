# 📋 Формы

**Раздел:** Контент → Формы · **Адрес:** `/admin/forms`

Конструктор форм: заявки, обратная связь, запись, бронирование, подписка.
Собирается мышью, вставляется шорткодом в любой материал.

</div>

---

## 🎯 Что это даёт

Форму под конкретную задачу — без программиста. Поля перетаскиваются, обязательность
и подсказки задаются переключателями, а всё присланное копится в панели и не
теряется, даже если письмо не дошло.

---

## 📦 Что уже готово после установки

Тринадцать форм на типовые случаи — их можно использовать как есть или взять за основу:

| | | |
|:---|:---|:---|
| Обратная связь | Запись на приём | Заявка на услугу |
| Обратный звонок | Расчёт стоимости | Отклик на вакансию |
| Отзыв о работе | Заявка от организации | Обращение или жалоба |
| Регистрация на мероприятие | Бронирование | Подписка на новости |
| Задать вопрос | | |

---

## 🚀 Быстрый старт

| Шаг | Действие |
|:--:|:---|
| 1 | **Формы → Создать** (или продублировать готовую) |
| 2 | Добавить поля из списка типов |
| 3 | У каждого поля: подпись, обязательность, подсказка, значок |
| 4 | Настройки: текст кнопки, сообщение после отправки, куда слать письмо |
| 5 | Скопировать шорткод и вставить в страницу или материал |

---

## 🧩 Типы полей

| Тип | Для чего |
|:---|:---|
| **Текст** | Имя, город, короткий ответ |
| **Многострочный текст** | Сообщение, комментарий |
| **Почта** | С проверкой формата |
| **Телефон** | С проверкой формата |
| **Число** | Количество, сумма |
| **Ссылка** | Адрес сайта |
| **Дата / Время** | Запись, бронирование |
| **Список** | Выбор одного из вариантов |
| **Переключатели** | Один вариант из нескольких, все видны сразу |
| **Флажок** | Да/нет |
| **Набор флажков** | Несколько вариантов сразу |
| **Файл** | Резюме, фото, документ |
| **Скрытое** | Служебное значение (например, источник заявки) |
| **Заголовок / Абзац** | Не спрашивают ничего — это разметка внутри формы |
| **Согласие** | Флажок «согласен на обработку данных» со ссылкой на политику |

> 📌 **Заметка**
> **Ширину поля задавать не нужно.** Телефон, дата и число сами встают в
> половину строки, а сообщение и списки — во всю: так форма читается лучше на
> любом экране.

## 📥 Полученные заявки

**Формы → у нужной формы «Заявки»**.

| Возможность | Как |
|:---|:---|
| Прочитать заявку | Клик по строке |
| Отметить прочитанной | Кнопка в карточке |
| Скачать присланный файл | Ссылка в карточке |
| Удалить | Кнопка в строке |

Непрочитанные подсвечиваются, счётчик виден в списке форм.

---

## 🛡️ Защита от роботов

Вставьте в форму [каптчу](каптча.md): либо шорткодом `[captcha preset="…"]` рядом
с формой, либо включив проверку в настройках формы.

---

## ⚠️ На что обратить внимание

> ⚠️ **Осторожно**
> **Письмо и запись в панели — разные вещи.** Заявка сохраняется всегда, даже
> если почта не настроена или письмо не ушло. Проверяйте раздел «Заявки», а не
> только почтовый ящик.

> ⚠️ **Осторожно**
> **Поле «Согласие» — не украшение.** Если форма собирает персональные данные
> (имя, телефон, почту), согласие со ссылкой на политику обязательно по закону.

> 💡 **Совет**
> **Не плодите формы под каждую страницу.** Одна форма может стоять в нескольких
> материалах — заявки всё равно копятся в одном месте. Скрытым полем можно
> пометить, откуда пришла заявка.

## ❓ Частые вопросы

<details>
<summary><b>Как поменять текст кнопки и сообщение после отправки?</b></summary>

В настройках формы — «Текст кнопки» и «Сообщение об успехе».
</details>

<details>
<summary><b>Куда приходят письма?</b></summary>

На адрес, указанный в настройках формы. Если он пуст, используется почта
администратора. Настройка почтового сервера — в установке или в `.env`.
</details>

<details>
<summary><b>Можно ли выгрузить заявки в таблицу?</b></summary>

Да, кнопкой выгрузки в списке заявок.
</details>
