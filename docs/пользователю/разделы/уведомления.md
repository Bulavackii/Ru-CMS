# 🔔 Уведомления

**Раздел:** Система → Уведомления · **Адрес:** `/admin/notifications`

Сообщения, которые видит посетитель сайта: плашка о cookie, акция, предупреждение
о работах.

</div>

---

## 🎯 Что это даёт

Способ сказать что-то всем посетителям сразу, не правя ни одну страницу. И
плашку о cookie, которую требует закон, — она уже заведена после установки.

---

## 🧩 Типы

| Тип | Для чего |
|:---|:---|
| 📝 **Текст** | Простое объявление |
| 🎨 **HTML** | Оформленное сообщение со ссылками и разметкой |
| 🍪 **Cookie** | Плашка согласия: показывается один раз, ответ запоминается |

---

## 🚀 Быстрый старт

| Шаг | Действие |
|:--:|:---|
| 1 | **Уведомления → Создать** |
| 2 | Тип, заголовок, текст |
| 3 | Кому показывать: всем, только гостям, только вошедшим, только администраторам |
| 4 | Когда показывать: период начала и конца |
| 5 | Как часто: один раз, каждый заход, до закрытия |
| 6 | Включить переключателем |

---

## ⚙️ Настройки показа

| Настройка | Смысл |
|:---|:---|
| **Аудитория** | Все · Гости · Вошедшие · Администраторы |
| **Период** | С какой по какую дату показывать |
| **Частота** | Одноразовое · при каждом заходе · пока не закроют |
| **Положение** | Сверху, снизу, по центру |
| **Значок** | Эмодзи или значок из набора |

Счётчик показов виден в списке — по нему понятно, сколько человек увидело
сообщение.

---

## ⚠️ На что обратить внимание

> ⚠️ **Осторожно**
> **Плашку о cookie не удаляйте.** Если сайт собирает любые данные посетителей
> (а счётчики их собирают), уведомление обязательно.

> ⚠️ **Осторожно**
> **Несколько одновременных уведомлений раздражают.** Показывайте одно; для
> второго задайте другой период.

> 💡 **Совет**
> **Одноразовое** — самый частый выбор для акций: посетитель увидит сообщение
> один раз и не будет натыкаться на него каждый заход.

## ❓ Частые вопросы

<details>
<summary><b>Уведомление включено, но его не видно</b></summary>

Проверьте период (не закончился ли), аудиторию (вы вошли как администратор —
а показ, например, только гостям) и частоту: одноразовое вы уже могли закрыть.
Проверять удобнее в приватном окне браузера.
</details>

<details>
<summary><b>Чем это отличается от колокольчика в панели?</b></summary>

Колокольчик — для вас: новые заказы, сообщения, отзывы. Этот раздел — про
сообщения посетителям сайта.
</details>
