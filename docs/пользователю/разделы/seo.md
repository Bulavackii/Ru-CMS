# 📈 SEO

**Раздел:** Система → SEO · **Адрес:** `/admin/seo/pages`

Как сайт выглядит в поиске: заголовки, описания, карта сайта, robots.txt,
перенаправления.

</div>

---

## 🎯 Что это даёт

Управление тем, что показывает Яндекс и Google: строка заголовка, описание под
ней, разрешение на индексацию. Плюс служебные файлы, которые поисковики читают
первыми.

---

## 📋 Список адресов

Каждой странице сайта соответствует запись. Она заводится автоматически при
создании материала, а кнопка **Синхронизировать** досоздаёт недостающие.

| Колонка | Смысл |
|:---|:---|
| **URL** | Адрес страницы |
| **Title / Description** | Что увидит человек в выдаче |
| **Индексация** | `index` / `noindex` — пускать ли поисковик |
| **Мета** | Отметки: canonical, Open Graph, JSON-LD |

---

## ✏️ Карточка адреса

| Поле | Как заполнять |
|:---|:---|
| **Title** | До ~60 знаков. Суть страницы + название сайта |
| **Description** | До ~160 знаков. Живое предложение, а не список ключевых слов |
| **Ключевые слова** | Практически не влияют; можно не заполнять |
| **Canonical** | Основной адрес, если одна и та же страница доступна по нескольким |
| **index / noindex** | Пускать ли в поиск |
| **follow / nofollow** | Переходить ли по ссылкам со страницы |
| **Open Graph** | Картинка и заголовок для превью в мессенджерах и соцсетях |
| **JSON-LD** | Разметка для расширенного вида в выдаче |

> 💡 **Совет**
> **Пустые поля не перезаписывают данные.** Оставили Title пустым — возьмётся
> заголовок материала.

---

## 🗺️ Служебные файлы

| Инструмент | Для чего |
|:---|:---|
| **Карта сайта** | Список адресов для поисковиков. Пересобирается кнопкой |
| **sitemap.xml** | Открыть готовый файл |
| **robots.txt** | Правила обхода: что можно, что нельзя |
| **Перенаправления** | Со старого адреса на новый, когда страница переехала |

---

## ↪️ Перенаправления

Если адрес страницы поменялся, заведите перенаправление: посетитель со старой
ссылки попадёт на новую, а поисковик перенесёт накопленный вес.

| Поле | Смысл |
|:---|:---|
| **Откуда** | Старый адрес |
| **Куда** | Новый адрес |
| **Тип** | 301 — навсегда, 302 — временно |

---

## ⚠️ На что обратить внимание

> ⚠️ **Осторожно**
> **`noindex` — сильное средство.** Поставив его по ошибке на важную страницу,
> вы уберёте её из поиска. Проверяйте, к какому адресу относится запись.

> ⚠️ **Осторожно**
> **Смена адреса без перенаправления теряет позиции.** Заведите его до того, как
> старый адрес перестанет работать.

> 💡 **Совет**
> **Синхронизацию стоит запускать после массового добавления материалов** —
> тогда у всех новых страниц появятся SEO-записи.

## ❓ Частые вопросы

<details>
<summary><b>Сайта нет в поиске</b></summary>

Проверьте: в robots.txt нет запрета; у страниц стоит `index`; карта сайта
собрана; сайт добавлен в Яндекс.Вебмастер и Search Console. Индексация занимает
недели.
</details>

<details>
<summary><b>В выдаче старый заголовок</b></summary>

Поисковик обновляет данные не сразу. Ускорить можно, отправив страницу на
переобход в панели вебмастера.
</details>

<details>
<summary><b>Что за строчка с фигурными скобками в JSON-LD?</b></summary>

Разметка для поисковиков. Если не уверены — не трогайте: сохраняется только
корректная запись, но неверная разметка хуже её отсутствия.
</details>
