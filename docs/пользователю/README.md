## 🆘 Если что-то не так

| Симптом | Что проверить |
|:---|:---|
| Правку не видно на сайте | Материал **опубликован**? Страница обновлена по-жёсткому (Ctrl + F5)? Часть блоков живёт в памяти до 5 минут |
| Пункт меню ведёт «в никуда» | Страница, на которую он ссылается, могла быть удалена или снята с публикации |
| Картинка не открывается | Файл загружен через **Медиатеку**, а не просто скопирован на сервер? |
| Письма не приходят | Раздел **Модули → Почта**; чаще всего дело в порте: нужен `587`, а не `465` |
| Заказ не оплачивается | В **Оплате** у способа должны быть введены ключи, и способ включён |

> ❗ **Важно**
> Ничего из перечисленного не требует программиста. Если раздел вообще не
> открывается или страница отдаёт ошибку — это уже к разработчику,
> [сюда](../разработчику/README.md).
