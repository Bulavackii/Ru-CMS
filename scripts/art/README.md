# Генераторы графики

Здесь лежат скрипты, которыми **собраны** фоны тем и баннеры слайдера. Сами
картинки закоммичены в `public/images/themes/backgrounds/` и
`modules/Slideshow/Resources/defaults/` — для работы сайта эти скрипты не
нужны. Они нужны, когда рисунок надо изменить.

> ⚠️ **Осторожно**
> Файлы SVG в тех каталогах править руками бессмысленно: следующий прогон
> генератора их перезапишет. Меняют генератор и пересобирают.

## Зачем скрипты, а не рисование руками

В каждом фоне порядка тысячи элементов: сеть узлов, грани кристалла, соты,
орбиты. Руками такое не правится и не переносится на другую палитру. Скрипт
же позволяет сменить один цвет и пересобрать все одиннадцать тем разом.

Случайность **сеяная**: тот же вызов даёт тот же файл. Иначе каждый прогон
менял бы вид сайта, и в git сыпались бы бессмысленные диффы.

## Как запустить

Нужен Python 3 — только для пересборки картинок, в зависимости проекта он не
входит. Запускать **из корня проекта**, пути внутри скриптов относительные:

```bash
python scripts/art/theme-backgrounds.py
python scripts/art/slideshow-banners.py
```

После пересборки картинки надо разложить по местам и обновить записи в базе:

```bash
php artisan themes:seed-default --reset
php artisan slideshow:seed-default --reset
php artisan cache:clear
```

## Что рисуют

### `theme-backgrounds.py` → `public/images/themes/backgrounds/*.svg`

Фон страницы для каждой из одиннадцати тем. Композиция одна и читается как
знак продукта: гранёное **ядро** (Core), **связи** от него к внешним узлам
(Nexum), **соты** — модульность, **орбиты** — каркас. От темы к теме меняются
палитра и разворот.

Края уходят в ровный цвет фона: слой повторяется (`background-repeat: repeat`),
и только так стык не виден.

### `slideshow-banners.py` → `modules/Slideshow/Resources/defaults/*.svg`

Четыре демо-баннера: два верхних и два нижних.

> ⚠️ **Осторожно**
> У этих картинок **нет собственного фона** — они прозрачные. Подложку рисует
> CSS из переменной темы (правило `.ru-slide` в
> `modules/Slideshow/Views/public/slideshow.blade.php`), поэтому баннер меняется
> вместе с оформлением сайта. Поэтому же графика в них нейтральная — белая с
> разной прозрачностью плюс чёрная для теневых граней: своего цвета у неё нет
> и спорить с подложкой нечем.

Долю затемнения подложки (сейчас 50 % и 32 % цвета темы) менять на глаз
нельзя: она проверена по всем одиннадцати темам. Узкое место — «Неон» с самым
светлым основным цветом; там белый текст даёт контраст 6.92, а второстепенный
`#dbeafe` — 5.67. Возьмёшь долю больше — «Неон» уйдёт ниже порога 4.5.
